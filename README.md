# このリポジトリに関して
このリポジトリは2024年度 電気通信大学 情報理工学域 情報系 メディア情報学プログラム・デザイン思考データサイエンスプログラム向けに開講された科目
「メディア情報学プログラミング演習」のグループプログラミングのために制作された脱出ゲームです。コンセプト等の説明は省きます。
jarファイルは[こちら(Download here)](https://drive.google.com/file/d/1b55C7YpC7WFEo4kfUtqXBOlTRLS9tFx2/view?usp=sharing)からダウンロード可能です。(2025/02/20時点)

※ ウイルスチェックは済んでいますが、念の為確認することを推奨します。  
※ このソフトウェアを用いたことで起こる問題の責任を一切製作者チームはとりません。  

プレイしてみての感想、意見、コードに対する意見等はこちらの[フォーム](https://forms.gle/8qZbBzaFvuv8qMFp7)にお願いいたします。

また、リファクタリング等大歓迎です。
# jarファイルの作成

ソースコードからjarファイルを作って実行したい場合、基本的なjar作成のコマンドをまとめたシェルファイルが用意されています。(現状Mac以外の動作を確認していません)build_mac.shを実行してください。
```
./build_mac.sh
```
